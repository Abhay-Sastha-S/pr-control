Read it like a river: each track is an independent chain — tracks run in parallel, and everything in the same wave column can merge simultaneously. A PR only lights up when its own wires are green. Tick Merged ✓ (saved in this browser) and watch the unlocks cascade. Wires come from: dependencies stated in the channel → stacked branches → shared Linear tickets → same-repo age (oldest first) → library before services, backend before frontend.

Merging is a human's call — the reviewer reviews and approves only. Merged to main lands on dev; prod promotion is a manually-triggered build (asked for in the channel), so it isn't derivable from GitHub and is not shown as automatic. GitHub / Linear data is a snapshot from the last sync; Slack threads in the detail panel are live via your Slack connector. Deploy-order blockers come from what was actually said in the channel (e.g. "merge backend first or the page 404s").
